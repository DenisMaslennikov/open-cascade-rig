# s0-t3 — first end-to-end pass through the cascade

**Date:** 2026-11-01. **Task:** training duration for one skill level given accumulated SP (product
repo `occc`, card #17, PR #8). **Purpose:** calibrate the pipeline, not the product.

## What ran

| Phase | Role | Model | Result |
|---|---|---|---|
| plan | architect | `deepseek-v4-pro` (glm-latest returned empty content at a 32k cap) | plan valid, 2 subtasks |
| tests frozen | specifier | `deepseek-v4-pro` | 1 commit, red gate green **on ImportError** — wrong reason |
| stubs | specifier (agent) | `glm-flash` | 3 files, red gate red on `NotImplementedError` |
| implementation | executor | `glm-flash` | green first attempt, 65 tests |
| review 1 | reviewer (read-only agent) | `deepseek-v4-pro` | 1 blocker (`target_level=0` silently returned zero), 1 minor docstring |
| fix | executor | `glm-flash` | blocker fixed |
| review 2 (PR) | reviewer_final via pr-agent | `qwen3.8-max` | 1 major: `NaN`/`inf` speed passed the guard |
| fix | executor | `glm-flash` | `math.isfinite` guard added |
| final review | reviewer_final via pr-agent | `qwen3.8-max` | no major issues, no points for the human |

## What it cost

- Review by an agent: $4.4–6.5 per round (`deepseek-v4-pro`), $26.2 for one `qwen3.8-max` agent run
  that produced no report. Same diff through pr-agent: ~5k tokens, cents.
- Executor runs: $0.17–0.25 each. Specifier: $0.42. Plans: ~$0.25.
- Wasted money in this run: a plan run killed by an empty answer, three review attempts killed by
  budget, one nine-minute `glm-flash` agent run that wrote nothing.

## What it taught (each item became a rule or a card)

1. Empty `content` at a 32k cap = reasoning budget, not a broken gateway → output caps now live in
   config, `null` means no limit.
2. Splitting tests and implementation into separate subtasks leaves no stubs → red gate can be green
   for the wrong reason; add a stub pass.
3. A reviewer agent is priced per turn → pr-agent for diffs, agent only when the repository matters.
4. Mutation testing found two holes two human-level reviews missed: a positive speed below 1 SP/min
   untested, and a level guard indistinguishable from delegation. 16 surviving mutants across
   `domain/skills`.
5. `glm-flash` on a brief without a red acceptance researches instead of writing.
