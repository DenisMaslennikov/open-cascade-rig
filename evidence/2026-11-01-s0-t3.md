The whole day of calibration came to **$11.01** at list prices, of which the product work (architect,
specifier, executor) is about **$0.41**.

Wasted work, same day: a plan run killed by an empty answer, three review attempts killed by the agent
budget, one `qwen3.8-max` agent run that produced no report, and one `glm-flash` run that researched for
nine minutes and wrote nothing. By token volume that is roughly a third of the day; by list price it is
about $6 — the gateway's own pricing made the same runs look like $44.

## Why the numbers changed

The first report quoted the local gateway: $93 for the day, $26 for a single review. Those are the
gateway's per-route overrides (30-70x the public list price), not what the work is worth on the open
market. Prices now come from OpenRouter, fetched weekly through the LAN proxy and cached outside the
repository.

## What it taught (each item became a rule or a card)

1. Empty `content` at a 32k cap = reasoning budget, not a broken gateway → output caps now live in
   config, `null` means no limit.
2. Splitting tests and implementation into separate subtasks leaves no stubs → red gate can be green
   for the wrong reason; add a stub pass.
3. A reviewer agent is priced per turn → pr-agent for diffs, agent only when the repository matters.
4. Mutation testing found two holes two human-level reviews missed: a positive speed below 1 SP/min
   untested, and a level guard indistinguishable from delegation. 16 surviving mutants across
   `domain/skills`.
5. `glm-flash` on a brief without a red acceptance researches instead of writing.
